# artam.io 🌐

سایت شخصی **artam** — یک صفحه معرفی مدرن، راست‌چین و ریسپانسیو.

## 📁 ساختار پروژه

```
artam.io/
├── index.html     ← صفحه اصلی سایت (HTML + CSS + JS)
├── images/        ← محل قرارگیری تصاویر سایت
└── README.md
```

## 🖼️ اضافه کردن عکس‌ها

عکس‌ها رو با همین نام‌ها داخل پوشه `images/` بذارید:

- `images/photo-1.jpg` — عکس اول
- `images/photo-2.jpg` — عکس دوم

سایت به‌صورت خودکار این عکس‌ها رو توی گالری نمایش میده (نیازی به تغییر کد نیست).
برای آپلود: مخزن در GitHub → پوشه `images` → Add file → Upload files → کامیت روی `main`.

## 🚀 اجرا و انتشار

- **اجرا روی لوکال:** فایل `index.html` رو مستقیم در مرورگر باز کنید.
- **انتشار:** سایت با GitHub Pages روی آدرس زیر منتشر می‌شه:

```
https://leilazare59-hub.github.io/artam.io/
```

هر تغییری که به `main` پوش بشه، به‌صورت خودکار روی سایت قرار می‌گیره.
