# artam.io 🌐

سایت شخصی **artam** — صفحه‌ی معرفی، مرکز خبر و آپدیت، به‌همراه بازی **«دنیای ماجراجویی»**.

## 📁 ساختار پروژه

```
artam.io/
├── index.html                  ← صفحه اصلی سایت (HTML + CSS + JS) + بخش بازی
├── news.json                   ← فید اخبار سایت
├── images/                     ← تصاویر سایت و کاور خبر
├── game/
│   ├── src/adventure-world.base.html   ← سورس اصلی بازی (مرجع، دست‌نخورده)
│   ├── index.html                       ← بازی با گرافیک نئون (ساخته‌شده)
│   └── adventure-world-neon.apk         ← اپ اندروید امضا‌شده (ساخته‌شده)
├── keystore/                   ← کلید امضای اختصاصی اپ
├── tools/                      ← ابزارهای ساخت، تست و امضا
└── docs/                       ← مستندات و تصاویر نمونه
```

## 🎮 بازی «دنیای ماجراجویی»

بازی HTML5 Canvas با ۶ فصل (بهار، تابستان، پاییز، زمستان، فضا، زهره) و ۱۵۰ مرحله،
فروشگاه، گردونه‌ی شانس و برج بی‌نهایت.

- **بازی در مرورگر:** [`game/index.html`](game/index.html)
- **اپ اندروید:** [`game/adventure-world-neon.apk`](game/adventure-world-neon.apk)
- **گرافیک:** نسخه‌ی نئون — آسمان شب، بلوم، شفق، پالت تازه‌ی هر فصل
  (برای جزئیات: [`docs/neon-update.md`](docs/neon-update.md))
- خاموش/روشن کردن جلوه‌ها: `تنظیمات → کیفیت گرافیک → جلوه‌های نئون`

### ساخت و تست بازی

```bash
npm install
npm run gfx          # ساخت game/index.html از سورس + لایه‌ی نئون
npm test             # اجرای بازی در Node برای گرفتن خطاهای runtime
npm run test:classic # تست رگرسیون پیکسلی (نئون خاموش = گرافیک قبلی)
npm run apk          # ساخت و امضای APK
npm run verify       # بازرسی مستقل امضای APK
npm run build        # همه‌ی مراحل
```

> پوشه‌ی `keystore/` را گم نکن؛ نسخه‌های بعدی اپ باید با همان کلید امضا شوند.

## 🖼️ اضافه کردن عکس‌های سایت

عکس‌ها را با همین نام‌ها داخل پوشه `images/` بگذارید:

- `images/photo-1.jpg` — عکس اول
- `images/photo-2.jpg` — عکس دوم

سایت به‌صورت خودکار این عکس‌ها را توی گالری نمایش می‌دهد (نیازی به تغییر کد نیست).
برای آپلود: مخزن در GitHub → پوشه `images` → Add file → Upload files → کامیت روی `main`.

## 📰 انتشار خبر جدید

فایل `news.json` را ویرایش کنید (یا از پنل ادمین داخل سایت کد خبر را بسازید و جایگزین کنید).
هر خبر: `title`، `text`، `img`، `vid`، `apk` و `date`.
