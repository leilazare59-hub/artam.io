# ✨ آپدیت گرافیک نئون — «دنیای ماجراجویی»

این سند توضیح می‌دهد چه چیزی به گرافیک بازی اضافه شده، چطور آن را روشن/خاموش کنی،
و چطور فایل APK اندروید از همین مخزن دوباره ساخته می‌شود.

---

## ۱) چه چیزی عوض شد؟

همه‌ی تغییرات **فقط روی لایه‌ی رندر** نشسته‌اند؛ منطق بازی، مراحل، دشمن‌ها، فروشگاه و
ذخیره‌ی بازی دست‌نخورده‌اند.

| جلوه | توضیح |
|---|---|
| 🌌 **آسمان شب نئونی** | هر فصل پالت شبانه‌ی مخصوص خودش را دارد؛ ستاره‌های چشمک‌زن، شفقِ موج‌دار و درخشش افق |
| 💡 **بلوم (Bloom)** | درخشش واقعی روی نقطه‌های نورانی صحنه، با دو بافر کوچک (۱/۴ اندازه) و آستانه‌ی روشنایی — هم سریع، هم ارزان برای گوشی |
| 🎞️ **وینیت و اسکن‌لاین** | تیرگی ملایم لبه‌های تصویر + خطوط اسکن نازک (حس مانیتور نئونی) |
| 🏔️ **لبه‌ی نورانی تپه‌ها** | سه لایه‌ی پارالاکس، هر کدام با رگه‌ی نور درخشان |
| 🌱 **نوار نور روی زمین** | خط درخشان روی سطح زمین + تیک‌های شبکه‌ای عمودی |
| 🏃 **افکت بازیکن** | هاله‌ی نئونی زیر پا، دنباله‌ی نوری هنگام دویدن/پرش، انفجار ذره‌ای در فرود و پرش |
| 🪙 **هاله‌ی سکه و ستاره** | سکه‌ها، سکه‌های طلایی و ستاره‌های امتیاز هاله‌ی درخشان می‌گیرند |
| 🟩 **سکوها** | لبه‌ی نئونی روی هر سکو |
| 🎬 **منوی اصلی** | آسمان شب، خورشید سینت‌ویو و کف شبکه‌ای با پرسپکتیو (به‌جای دشت سبز قبلی) |
| 🌋 **زهره و فضای سیاه‌چال** | اخگرهای بالارونده برای زهره، سنگ‌نوشته‌های نئونی تپنده برای سیاه‌چال |

### بین حالت جدید و قدیم جابه‌جا شو

`تنظیمات → کیفیت گرافیک → جلوه‌های نئون` (کلید **روشن/خاموش**)

- خاموش کردن این کلید، بازی را **دقیقاً** به همان ظاهر قبلی برمی‌گرداند
  (تست خودکار پیکسل‌به‌پیکسل این را ثابت می‌کند: `npm run test:classic`).
- در کیفیت گرافیک «پایین»، جلوه‌های نئون خودکار خاموش می‌شوند تا اجرا روان بماند.
- زبان فارسی/انگلیسی و کلیدهای تازه خودکار هماهنگ می‌شوند.

## ۲) ساختار پروژه بعد از این آپدیت

```
artam.io/
├── index.html                  ← سایت + بخش «بازی» با دکمه‌ی بازی و دانلود
├── news.json                   ← خبر آپدیت گرافیک
├── images/neon-preview.jpg     ← کاور خبر
├── game/
│   ├── src/adventure-world.base.html   ← سورس اصلی بازی، دست‌نخورده (مرجع)
│   ├── index.html              ← خروجی نهایی با گرافیک نئون  (ساخته‌شده)
│   └── adventure-world-neon.apk        ← اپ اندروید امضا‌شده   (ساخته‌شده)
├── keystore/                   ← کلید امضای اختصاصی اپ (یک‌بار ساخته می‌شود)
├── tools/
│   ├── apply-neon.py           ← لایه‌ی نئون را روی سورس می‌نشاند
│   ├── smoke-test.js           ← اجرای واقعی بازی در Node (تشخیص خطای runtime)
│   ├── compare-classic.js      ← تست رگرسیون گرافیک (مقایسه‌ی پیکسلی)
│   ├── render-frames.js        ← رندر فریم‌های واقعی بازی به PNG
│   ├── make-keystore.js        ← ساخت کلید و گواهی امضا
│   ├── build-apk.js            ← ساخت و امضای APK
│   └── verify-apk.py           ← بازرسی مستقل امضای APK
└── docs/neon-preview/          ← تصاویر نمونه‌ی هر فصل
```

---

## ۳) دستورها

```bash
npm install          # نصب ابزارها (فقط برای توسعه)

npm run gfx          # ساخت game/index.html از سورس + لایه‌ی نئون
npm test             # اجرای بازی در Node: همه‌ی فصل‌ها، صفحه‌ها و کیفیت‌ها
npm run test:classic # تست رگرسیون: نئون خاموش = عیناً گرافیک قبلی
npm run render       # رندر نمونه‌ها در docs/neon-preview

npm run keys         # یک‌بار: ساخت کلید امضای اختصاصی (keystore/)
npm run apk          # ساخت و امضای game/adventure-world-neon.apk
npm run verify       # بازرسی مستقل امضا (JAR v1 + APK v2 + v3)

npm run build        # همه‌ی مراحل بالا به‌ترتیب
```

سورس اصلی بازی (`game/src/adventure-world.base.html`) هرگز تغییر نمی‌کند؛
`game/index.html` همیشه از صفر از روی آن ساخته می‌شود. برای برگشت به حالت قبل
کافی است فایل خروجی را حذف کنی.

## ۴) نصب اپ اندروید

فایل: **`game/adventure-world-neon.apk`**

1. فایل را روی گوشی دانلود کن (از سایت یا از همین مخزن).
2. اگر نسخه‌ی قبلی بازی نصب است، **اول حذفش کن** — چون امضای این نسخه کلید
   اختصاصی خودمان است و اندروید اجازه‌ی «آپدیت روی نسخه‌ی دیگر» را نمی‌دهد.
3. نصب از منابع نامعتبر (Install unknown apps) را برای مرورگر/فایل‌منیجر روشن کن.
4. فایل را باز کن و نصب کن.

### امضای APK

بسته با سه طرح استاندارد اندروید امضا شده است:

```
طرح‌های امضا: v1 (JAR) + v2 + v3
خورده‌ی SHA-512 خوشه‌ای:  ✓ درست
امضای v2 / v3:            ✓ معتبر
امضای v1:                 448 فایل بررسی شد، همه سالم
گواهی:                    C=IR, OU=Games, O=Artam, CN=Artam Adventure World
```

بازرسی مستقل (بدون apksigner و بدون Java) با `npm run verify` انجام می‌شود:
خورده‌ی محتوا را از نو حساب می‌کند، امضای RSA را با کلید گواهی داخل بسته
می‌سنجد و جدول `MANIFEST.MF` را برای همه‌ی فایل‌ها چک می‌کند.

> ⚠️ **مهم:** پوشه‌ی `keystore/` را گم نکن. برای انتشار نسخه‌های بعدی باید با همان
> کلید امضا کنی، وگرنه کاربر باید اپ قبلی را حذف کند. (پوشه در مخزن کامیت شده است
> تا گم نشود؛ اگر روزی مخزن عمومی شد، این کلید فقط برای همین بازی است و ارزش دیگری ندارد.)

## ۵) اگر خودت خواستی جلوه‌ای اضافه/کم کنی

همه‌ی جلوه‌ها در یک بلوک مشخص در `tools/apply-neon.py` (بخش `NEON ENGINE`) جمع شده‌اند:

- تابع‌های `neonXXX` هر کدام یک جلوه‌ی مستقل‌اند؛ حذف/جابه‌جای یک خط کافی است.
- نقطه‌ی اتصال به موتور بازی، پچ‌های شماره‌دار در همان فایل‌اند (`PATCHES`).
- برای تغییر شدت درخشش: `neonBloom()` → مقادیر `globalAlpha` (پیش‌فرض ۰.۲۸ و ۰.۴۵).
- برای تغییر پالت‌ها: دیکشنری‌های `NEON_ACCENT` و `NEON_THEMES`.
- بعد از هر تغییر: `npm run gfx && npm test && npm run test:classic`.
